# AXI4-Lite to APB Bridge

## Overview
Designed and implemented an **AXI4-Lite to APB Bridge** using Verilog/SystemVerilog to enable communication between high-performance AXI4-Lite and low-power APB peripherals.

## Key Features
- AXI4-Lite read and write transaction handling.
- APB protocol signal generation.
- Modular RTL architecture.
- FSM-based transaction control.
- Address decoding and error handling.
- APB wait-state support.

## Tools & Technologies
- Verilog / SystemVerilog
- EDA Playground
- Icarus Verilog
- GTKWave
- Git & GitHub

## Verification
Verified using a SystemVerilog testbench and APB slave model, covering read/write transactions, address decoding, wait states, and error responses.

## Learning Outcomes
- AMBA AXI4-Lite and APB protocols.
- RTL design and FSM implementation.
- Hardware handshaking.
- Functional verification and waveform analysis.
